# Wolf524 — اكتشاف ومراقبة عملات Solana عبر Telegram

يبحث البوت تلقائيًا في ملفات التوكنات الحديثة التي تعرضها DexScreener، يفحص مجموعة صغيرة منها، ويرسل قائمة مرشحين بناءً على فلاتر سوقية وروابط المشروع العامة. لا تحتاج إدخال عنوان العقد للبحث عن المرشحين.

## اكتشاف وتنبيهات

- `/discover` — بحث الآن، يفحص حتى 5 توكنات Solana الجديدة (يمكن تعديل `MAX_SCAN_PER_CYCLE` في إعدادات البيئة، بحد أقصى 10).
- `/autodiscover on` — تنبيهات دورية كل 15 دقيقة تقريبًا.
- `/autodiscover off` — إيقاف التنبيهات.

الفلاتر الحالية: مؤشر مخاطر أولي ≤35، سيولة ≥$15K، حجم 24 ساعة ≥$5K، 20 معاملة على الأقل، ورابط عام واحد على الأقل. ترتيب النتائج يبدأ بالأقل نقاط مخاطر ثم الأكثر تنوعًا في الروابط. هذه فلاتر فرز وليست إشارات شراء.

### ماذا يعني فحص المجتمع؟

الإصدار الحالي يجمع روابط X/Telegram/Discord/الموقع التي يعلنها DexScreener ويعرضها ويحسب تنوع فئات الروابط فقط. **لا** يقيس عدد الأعضاء أو التفاعل أو مشاعر المنشورات ولا يثبت أن الحسابات أصلية. فحص محتوى المجتمع بشكل موثوق يحتاج مزودي بيانات/واجهات رسمية ومفاتيح API مستقلة، ولم تتم إضافة أي scraping أو تجاوز لقيود المنصات.

## أوامر أخرى

- `/scan <mint>` — فحص عقد SPL على Solana.
- `/watch <mint>` و`/unwatch <mint>` — إدارة قائمة المراقبة.
- `/watchlist` — عرض قائمتك.
- `/top` — ترتيب العملات المراقبة حسب مؤشر المخاطر.

## النشر على Railway

1. اربط GitHub repo `wwhrksb5t4-svg/Wolf524` بخدمة Railway، مع استخدام Dockerfile الموجود في جذر الريبو والذي يبدأ `runner.py`.
2. من **Service → Variables** أضف `BOT_TOKEN` بقيمة توكن @BotFather، ثم طبّق التغييرات/أعد النشر.
3. أضف Volume إلى الخدمة وعيّن Mount Path إلى `/data`، ثم أضف `DATABASE_PATH=/data/wolf524.db` كي تبقى قوائم المستخدمين وبيانات الاكتشاف بعد إعادة التشغيل.
4. عندما تكون الخدمة Running، افتح البوت وأرسل `/start` ثم `/autodiscover on`.

لا تضع التوكن في GitHub أو المحادثات. إذا انكشف، ألغِه من BotFather وأنشئ غيره.

## حدود البيانات والتحذير

مصدر الاكتشاف ليس قاعدة شاملة لكل عملات الميم؛ قد يفوّت توكنات أو تتأخر بياناته. الجولة تفحص عددًا محدودًا لتقليل الضغط وحدود API. أعداد الشراء/البيع هي معاملات وليست مشترين فريدين. أكبر الحائزين حسابات توكن وقد لا تمثل محافظًا فريدة. عمر زوج التداول ليس بالضرورة عمر إنشاء العملة.

البوت لا يستطيع ضمان أن تكون من أوائل المستثمرين ولا يضمن اكتشاف rug pull أو قابلية البيع. هذه أداة معلومات/فرز وليست نصيحة استثمارية؛ تحقق بنفسك ولا تستثمر ما لا تتحمل خسارته.
