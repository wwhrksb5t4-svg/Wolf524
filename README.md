# نشر Wolf524 وتشغيله على Telegram

البوت الآن مجهز كـ **Background Worker** عبر Docker/Render؛ لا يحتاج رابط ويب. إعداد `render.yaml` يحفظ قاعدة SQLite على قرص دائم حتى تبقى قائمة المراقبة بعد إعادة التشغيل.

## المطلوب مرة واحدة منك

لا أستطيع إنشاء خدمة استضافة أو إدخال توكن Telegram الخاص بك نيابةً عنك؛ يلزم ربط حساب الاستضافة وتعيين السر بنفسك. لا ترسل التوكن هنا ولا تضعه داخل GitHub.

1. أنشئ البوت في [@BotFather](https://t.me/BotFather) باستخدام `/newbot` وانسخ التوكن.
2. سجّل الدخول إلى [Render](https://render.com/) واربط حساب GitHub الذي يحتوي `wwhrksb5t4-svg/Wolf524`.
3. من Render اختر **New → Blueprint**, ثم اختر المستودع والفرع `main`.
4. وافق على إعداد `wolf524-telegram-bot`. عند طلب `BOT_TOKEN` أدخل التوكن كـ Secret في Render فقط.
5. أنشئ الخدمة. انتظر حتى تصبح حالتها **Live**، ثم افتح اسم البوت في Telegram وأرسل `/start`.

> خدمة Background Worker والقرص الدائم قد يترتب عليهما رسوم حسب خطة Render الحالية. راجع السعر في لوحة Render قبل تأكيد الإنشاء. لا تغيّر الخدمة إلى Web Service: البوت يعمل عبر polling.

## التشغيل المحلي للاختبار

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
```

عيّن `BOT_TOKEN` كمتغير بيئة في الطرفية (أو استخدم ملف `.env` محليًا إذا أضفت دعم dotenv)، ثم شغّل `python bot.py`.

## أوامر Telegram

- `/start` و`/help` — التعليمات.
- `/scan <mint>` — فحص توكن Solana.
- `/watch <mint>` — إضافة للقائمة.
- `/unwatch <mint>` — إزالة من القائمة.
- `/watchlist` — عرض قائمتك.
- `/top` — ترتيب العملات المراقبة حسب أقل نقاط مخاطر.

يفحص البوت هبوط السيولة دوريًا كل 5 دقائق افتراضيًا. يجب أن تبدأ المحادثة مع البوت وتستخدم `/start` قبل تلقي التنبيهات.

## الأمان والحدود

- التوكن كلمة مرور: لا تضعه في README أو ملفات الريبو. إذا انكشف، ألغِه عبر BotFather وأنشئ توكنًا جديدًا.
- بيانات DexScreener وRPC قد تتأخر أو تخضع لحدود استخدام؛ يمكن تعيين مزود RPC آخر من `SOLANA_RPC_URL`.
- الفحص تقريبي وليس نصيحة استثمارية ولا يضمن اكتشاف الاحتيال أو سحب السيولة. عدد الشراء/البيع هو عدد معاملات، وتركيز الحيازة محسوب على أكبر حسابات التوكن وليس محافظًا فريدة بالضرورة.
