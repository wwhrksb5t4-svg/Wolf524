# Wolf524 — اكتشاف ومراقبة عملات Solana عبر Telegram

البوت يبحث تلقائيًا عن ملفات التوكنات الحديثة التي يعرضها DexScreener، ثم يفحص عددًا محدودًا من توكنات Solana في كل جولة. لا تحتاج لإدخال عنوان العقد للبحث عن المرشحين.

## اكتشاف تلقائي

- `/discover` — ابحث الآن وافحص حتى 5 توكنات Solana جديدة.
- `/autodiscover on` — اشترك في تنبيهات المرشحين المكتشفين تلقائيًا (الفحص كل 15 دقيقة تقريبًا).
- `/autodiscover off` — أوقف التنبيهات.

الفلترة الأولية الحالية تشترط مؤشر مخاطر ≤35، وسيولة ≥$15K، وحجم 24 ساعة ≥$5K، و20 معاملة على الأقل. هذه حدود قابلة للتعديل داخل `runner.py` وليست دليلًا على أن العملة آمنة أو استثمار جيد. لا نرسل إلا المرشحين الذين اجتازوا الحدود؛ لا يعني غياب تنبيه أن بقية العملات آمنة.

## النشر على Railway

1. اربط GitHub repo `wwhrksb5t4-svg/Wolf524` بخدمة Railway.
2. تأكد أن الخدمة تستخدم Dockerfile في جذر الريبو؛ يبدأ الآن عبر `python runner.py`.
3. من **Service → Variables** أضف `BOT_TOKEN` بقيمة توكن @BotFather، ثم طبّق التغييرات/أعد النشر.
4. لتخزين SQLite بشكل مستمر، أضف Volume إلى الخدمة وعيّن Mount Path إلى `/data`، ثم أضف المتغير `DATABASE_PATH=/data/wolf524.db`.
5. بعد أن تصبح الخدمة Running، افتح البوت وأرسل `/start` ثم `/autodiscover on`.

لا تضع التوكن في GitHub ولا ترسله في المحادثات. إذا انكشف التوكن، ألغِه من BotFather وأنشئ غيره.
