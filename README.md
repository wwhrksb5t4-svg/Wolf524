# Wolf524 — بوت مراقبة توكنات Solana عبر Telegram

بوت Python يفحص توكنات SPL على شبكة Solana، ويتيح قائمة مراقبة شخصية وتنبيهًا عند هبوط السيولة.

## الوظائف

- حجم تداول 24 ساعة والسيولة والسعر من DexScreener.
- عدد عمليات الشراء والبيع خلال 24 ساعة (هذه أعداد معاملات، وليست عدد محافظ مشترية/بائعة فريدة).
- عمر زوج التداول كبديل تقريبي لعمر الإدراج؛ لا يثبت تاريخ إنشاء التوكن.
- توزيع أكبر 10 حسابات توكن وصيلاحيات Mint وFreeze عبر Solana RPC.
- مؤشر مخاطر استدلالي، وعرض أكبر الحسابات، وترتيب قائمة المراقبة حسب أقل نقاط مخاطر.
- تنبيه دوري كل 5 دقائق افتراضيًا إذا انخفضت السيولة 20% أو أكثر منذ آخر فحص.
- روابط DexScreener وSolscan ورابط فتح DexScreener في متصفح Phantom.
- قائمة مراقبة محفوظة محليًا في SQLite لكل مستخدم Telegram.

> حدود مهمة: فحص أكبر 10 حسابات يعدّ حسابات التوكن، وقد تكون عدة حسابات مرتبطة بمحفظة واحدة. لا يفحص هذا الإصدار قفل السيولة أو مالكها، ولا يضمن اكتشاف السحب أو الاحتيال أو قابلية البيع. مؤشر المخاطر تقريبي وليس توصية مالية.

## المتطلبات

- Python 3.10 أو أحدث.
- توكن بوت من [@BotFather](https://t.me/BotFather).

## التثبيت والتشغيل

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
cp .env.example .env
```

ضع التوكن في `.env`:

```env
BOT_TOKEN=توكن_البوت_هنا
```

ثم شغّل:

```bash
python bot.py
```

يمكن ضبط `SOLANA_RPC_URL` على مزود RPC خاص لرفع حدود الاستخدام. لا تشارك ملف `.env` أو ترفع التوكن إلى GitHub.

## أوامر Telegram

- `/start` أو `/help` — التعليمات.
- `/scan <mint>` — فحص توكن Solana.
- `/watch <mint>` — إضافة للقائمة.
- `/unwatch <mint>` — إزالة من القائمة.
- `/watchlist` — عرض قائمتك.
- `/top` — فحص وترتيب حتى 20 عملة مراقبة حسب أقل نقاط مخاطر.
- `/status` — حالة البوت.

يبدأ التنبيه للمستخدم بعد أن يرسل للبوت رسالة ويضيف عملة لقائمته، لأن Telegram لا يسمح للبوت ببدء محادثة خاصة من تلقاء نفسه.
