# Wolf524 — اكتشاف ومراقبة عملات Solana عبر Telegram

يبحث البوت تلقائيًا عن توكنات Solana في عدة خدمات فهرسة عامة، ثم يفحص بيانات السوق والمخاطر ويرسل مرشحين للمراجعة. لا تحتاج إدخال عنوان العقد للبحث.

## مصادر وأدوات

- **DexScreener:** ملفات التوكنات الحديثة، boosts، والسيولة والحجم وعدد معاملات الشراء/البيع.
- **GeckoTerminal:** مجمعات السيولة الجديدة على Solana.
- **Solana RPC:** صلاحيات Mint/Freeze وأكبر حسابات التوكن.
- **RugCheck:** إثراء اختياري بنتيجة/ملاحظات تقرير المخاطر العامة عند توفرها.
- **Birdeye:** مصدر إضافي للتوكنات الجديدة؛ اختياري ويتطلب مفتاح API مجانيًا/مدفوعًا بحسب خطة مزود الخدمة.

مزودو الفهرسة ليسوا قاعدة شاملة لكل عملة، وقد تتأخر بياناتهم أو تفوتهم إطلاقات. لا يمكن ضمان أن تكون أول مستثمر.

## أوامر Telegram

- `/discover` — بحث وفحص الآن.
- `/autodiscover on` — تنبيهات دورية للمرشحين.
- `/autodiscover off` — إيقافها.
- `/scan <mint>` — فحص عقد محدد.
- `/watch <mint>` و`/unwatch <mint>` — إدارة قائمة المراقبة.
- `/watchlist` و`/top` — عرض وترتيب قائمتك.

تُضبط الفلاتر بمتغيرات البيئة: `DISCOVERY_INTERVAL_SECONDS` (300 ثانية افتراضيًا، حد أدنى 120)، `MAX_SCAN_PER_CYCLE` (8 افتراضيًا، حد أقصى 15)، `MIN_CANDIDATE_LIQUIDITY_USD` (5000)، `MIN_CANDIDATE_VOLUME_24H_USD` (1000)، `MIN_CANDIDATE_TRADES_24H` (10)، `MAX_CANDIDATE_RISK_SCORE` (50). زد فترة البحث أو استخدم RPC موثوقًا إذا واجهت حدود الاستخدام.

### تفعيل Birdeye (اختياري)

أنشئ مفتاحًا من مزود Birdeye، ثم أضف في إعدادات Railway متغيرًا سريًا اسمه `BIRDEYE_API_KEY` وأعد النشر. إذا لم تضفه، يستمر البوت بمصادر DexScreener وGeckoTerminal. لا تضع المفتاح في GitHub أو المحادثات.

## النشر على Railway

اربط مستودع `wwhrksb5t4-svg/Wolf524` بخدمة Docker. في **Service → Variables** أضف `BOT_TOKEN` (توكن @BotFather) وطبّق التغييرات/أعد النشر. لإبقاء SQLite بعد إعادة التشغيل، أضف Volume بمسار `/data` وأضف `DATABASE_PATH=/data/wolf524.db`. بعد أن تصبح الخدمة Running، افتح البوت وأرسل `/start` ثم `/autodiscover on`.

## تحذير وحدود

RugCheck قد لا يستجيب أو تتغير واجهته؛ عدم توفر نتيجته لا يعني أن التوكن آمن. النتيجة المحلية وRugCheck ليستا ضمانًا ضد الاحتيال أو سحب السيولة أو عدم قابلية البيع. الروابط الاجتماعية لا تثبت نشاط المجتمع أو صحة الحسابات. أعداد الشراء/البيع هي معاملات وليست مشترين فريدين، وأكبر الحسابات قد لا تمثل محافظًا منفصلة. هذه قائمة بحث وليست توصية استثمارية؛ قد تخسر كامل المبلغ. لا تشارك seed phrase أو مفاتيح محفظتك.
