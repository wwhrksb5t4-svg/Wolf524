# Wolf524 — اكتشاف ومراقبة عملات Solana عبر Telegram

يبحث البوت تلقائيًا في عدة مصادر فهرسة عامة، ويجمع التوكنات الجديدة التي تظهر في DexScreener وGeckoTerminal، ثم يفحص بيانات السوق والمخاطر ويرسل مرشحين للمراجعة. لا تحتاج إدخال عنوان العقد للبحث.

## مصادر الاكتشاف والفحص

- DexScreener: أحدث ملفات التوكنات والـ token boosts، بالإضافة إلى بيانات الأزواج والسيولة والحجم والمعاملات.
- GeckoTerminal: قائمة المسابح الجديدة على شبكة Solana.
- Solana RPC: صلاحيات التوكن وتركيز أكبر حسابات الحيازة.
- روابط المجتمع العامة المتاحة في ملفات DexScreener: تُعرض للفتح اليدوي فقط؛ لا نقيس حجم المجتمع أو التفاعل أو صحة الحسابات.

لا توجد قاعدة عامة واحدة تضم كل الميم كوين. هذه المصادر لا تغطي كل الإطلاقات لحظيًا وقد تتأخر أو تفوّت توكنات. البوت لا يستطيع ضمان أن تكون أول مستثمر أو أن يلحق بالشراء قبل الآخرين.

## أوامر البحث

- `/discover` — بحث فوري وفحص مجموعة من التوكنات المكتشفة حديثًا.
- `/autodiscover on` — تشغيل تنبيهات المرشحين الجدد دوريًا.
- `/autodiscover off` — إيقاف التنبيهات.
- `/scan <mint>` — فحص عقد محدد.
- `/watch <mint>` و`/unwatch <mint>` — إدارة قائمة المراقبة.
- `/watchlist` و`/top` — عرض وترتيب قائمة المراقبة.

إعدادات اختيارية كمتغيرات Railway: `DISCOVERY_INTERVAL_SECONDS` (الافتراضي 300 ثانية، الحد الأدنى 120)، `MAX_SCAN_PER_CYCLE` (الافتراضي 8، الحد الأعلى 15)، `MIN_CANDIDATE_LIQUIDITY_USD` (5000)، `MIN_CANDIDATE_VOLUME_24H_USD` (1000)، `MIN_CANDIDATE_TRADES_24H` (10)، `MAX_CANDIDATE_RISK_SCORE` (50). زيادة عدد الفحوصات أو تكرارها قد يؤدي إلى حدود استخدام المصادر العامة أو RPC.

## النشر على Railway

اربط مستودع `wwhrksb5t4-svg/Wolf524` بخدمة Docker. في **Service → Variables** أضف `BOT_TOKEN` (توكن @BotFather) وطبّق التغييرات/أعد النشر. لدوام قاعدة البيانات أضف Volume بمسار `/data` ومتغير `DATABASE_PATH=/data/wolf524.db`. بعد أن تصبح الخدمة Running، افتح البوت وأرسل `/start` ثم `/autodiscover on`.

لا تضع التوكن في GitHub أو المحادثات. إذا انكشف، ألغِه من BotFather وأنشئ غيره.

## معنى الترتيب وحدوده

تُرشّح النتائج بحسب حدود قابلة للتعديل للسيولة والحجم وعدد المعاملات ومؤشر مخاطر تقريبي، ثم ترتب حسب انخفاض المخاطر وارتفاع السيولة والحجم. هذا ليس تنبؤًا بالعائد أو إشارة شراء. أعداد الشراء/البيع هي معاملات وليست مشترين فريدين؛ أكبر الحسابات لا تثبت ملكية محافظ مستقلة؛ عمر زوج التداول ليس عمر إنشاء التوكن؛ ووجود روابط اجتماعية لا يثبت نشاط المجتمع أو شرعيته. لا يوجد ضمان ضد الاحتيال أو سحب السيولة أو عدم القدرة على البيع، وقد تخسر كامل المبلغ. تحقق بنفسك ولا تشارك seed phrase أو مفاتيح المحفظة.
